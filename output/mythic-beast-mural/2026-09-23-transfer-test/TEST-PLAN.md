## 测试范围

- 烛龙：验证长躯体、人面与无翼无足结构能否继承同一套细线和平面叠层；彩色阶段验证红色主导，而非照搬穷奇配色。
- 毕方：验证鸟类与一足结构、羽片分组及清峻气质；彩色阶段验证青身红纹白喙。
- 每只先生成灰阶，再以灰阶为编辑目标进行彩色试稿。上色前进行 agent 结构检查，明显错误最多做一次定点修正。
- 此次连续生图属于用户要求的 Skill 实测。彩色稿是候选预览，黑白稿和新彩稿都不标记为用户认可。

## 人工验收维度

1. **同系列感**：与穷奇比较，线条、平面化、形块叠层与精细度是否对味？
2. **角色独立性**：是否一眼能分清异兽，且没有套用穷奇的脸、姿态和器官？
3. **结构保持**：灰阶到彩色后，姿态、器官、主纹样和留白是否保持？
4. **个人偏好**：古意、气质、疏密和颜色是否达到你希望的精美程度？

反馈可写：`图号 + 保留/修改/淘汰 + 具体部位或感觉`。风格满意与形态正确分开判定。

## 实测边界

两种角色各一次初始生成只能检验迁移方向与流程是否可运行，不能证明跨多次随机生成的稳定性。人工确认后，再选择同条件重复生成或更多身体类型进行第二轮验证。
