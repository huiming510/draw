# 风格规范 v0.10

## 当前优先级

先以穷奇参考和代表性试稿确认整体画风，再定制每只异兽的细节。先判断线条是否轻细且有层级、空间是否平面化、装饰是否精密而有疏密、整体是否保有壁画古意与流动感，以及色彩是否克制。此时不要求确定具体背景、边框、发饰或每个纹样。

下面的绘画语言是从已认可穷奇提炼的工作依据；跨角色是否成立仍需人工验证。“背景语义与系列变化”留给画风确认后的定制阶段。本轮晦明层山、玉石火迹均为提前做出的探索方案，尚未取得用户认可。

## 固定的绘画语言

1. **细线组织的平面装饰画。** 壁画古意结合舒展的装饰曲线；外形、内部结构、微纹的线条有轻重，但不出现统一粗黑描边。纹样细而清楚，线宽随结构转折变化。
2. **空间来自形块关系。** 以清晰的遮挡、错位、穿插和嵌套形成前后。单个形块保持平涂。身体不是靠高光、渐变、投影塑出的三维体积。
3. **主曲线贯穿整体。** 躯体及其附属结构具有连续的节奏；每种身体都重新设计曲线，不把穷奇的尾卷和翼形当作通用模板。
4. **三个细节尺度。** 大轮廓完整，中层装饰片块丰富，小纹饰集中在结构允许的位置。脸和身份特征有可读的安静区域；细密不等于把每寸画面填满。
5. **纹饰从形态生长。** 羽、鳞、毛、甲各自具有结构方向和分组方式。借用同一套画法，重新设计具体图案。器官不能被表面纹样替代。
6. **克制的矿物色。** 主色主导，辅色区分相邻结构，强调色少量使用。细线可为暖金、墨色或浅色，以可读性为准。色彩由角色决定。
7. **古意来自绘画处理。** 轻微纸壁颗粒、有限色和装饰节奏足够；不以大片破损、褪色、污渍或浮雕质感替代。

## 允许变化

| 项目 | 变化原则 |
| --- | --- |
| 体型与姿态 | 按异兽身份重新设计，允许蛇、鸟、鱼、囊状等结构 |
| 画幅、朝向、重心 | 服务新角色轮廓，整体仍饱满且有呼吸空间 |
| 色相与冷暖 | 服从文献规定及本次创作方案，可与穷奇显著不同 |
| 纹样 | 和该角色身体、气质、语义相连，不复制虎纹 |
| 背景与边缘装饰 | 从角色环境与神话语义设计；可开口、局部装饰或无框，不默认云气、圆环与四角花饰 |
| 性格 | 凶、静、灵、诡、憨等均可，不能全部画成龇牙猛兽 |

## 将奇异形态转译为可欣赏的角色

用户提出的图册优势是把原著描述中显得诡异的异兽化为可接受的形象。保留特征的可辨识性，同时让形体关系自洽、神态有灵性、视觉感受舒适；威严、力量和神秘感仍可保留，不等于统一温顺、幼态或美人化。

- 复合身体先设计连续轮廓、相邻比例和轴线，再处理材质／纹样过渡。人面可表现为同一异兽头首中的人类五官，不必照搬独立的人头、发型和人类颈肩。
- 用户也可选择通过倒影等视觉关系表达复合身份。例如本轮烛龙实体为睁眼的蛇，水中显出闭眼人面；验收其对应与反射是否清楚，而非强制生成人头蛇身。这种改编明确记录为创作选择，不能推广成所有异兽的固定方案。
- 尾、发、鳞片和装饰带在大小、轮廓与连接上区分，避免多个尖端被读成多条尾或多段身体。长躯要兼顾连贯与自然盘曲，用弧线松紧、腹带和遮挡组织穿插；不能把结构清楚简单等同于取消盘绕、拉成单向波形。
- 盘绕长躯先确定从头到尾的唯一连续路径，再组织粗细、遮挡与纹样。每处交叉须能指出哪段在前，后段从两侧露出时的轴线、宽度与腹带转面须接得上。先追中心路径，再追两侧边界；不能仅凭单头单尾或局部曲线好看判定成立。用户指定保留原盘法时，锁定大回环的位置、方向、主要负形与尾端，只修局部接续及腹鳞朝向；不得为方便核验改成螺旋、移尾或取消回环。不要用岩石、密纹和投影掩盖连接。
- 文字修正后仍反复接错时，可按原有大弧制作单独的中心线结构参考，标清每次上下穿越，再与原画一起输入生图工具。结构图连通只能证明设计路线可行，不能代替对最终插画的检查；成图须去掉诊断线、编号和辅助配色。
- 路径连续后仍要判断体态与受力：需要丰润、松弛的长躯时，以宽缓转弯、自然粗细、接触处轻微压扁和无承托处的下垂表现重量，避免均匀圆管、绷紧的绳索或悬浮拱桥。只加粗不能修复受力；保留盘法时仍可按修改目标调整局部高度与躺卧方向，不必锁死不自然的竖直拱形。腹面须随真实转面显隐，不能每段都朝向观者而像扭带。丰满不能堵掉交叉处的可读边界。沿用平面画法，用轮廓和形块关系表现承托，不靠写实体积打光。
- 用简练神态与有节制的特征塑造情绪，避免用写实人皮、突兀颈部、獠牙瞪眼等无关细节放大诡异感。不能以全都可爱化来消除异兽差异。
- 把“核心身份是否还在”和“融合后是否自然、愿意观看”分别验收；形式上遵守文字描述不自动代表形象设计成功。

## 背景语义与系列变化

用户反馈：背景纹样要和异兽的背景相匹配，避免千篇一律和视觉疲劳；看起来是一套图，每幅又有独特的吸引力。系列一致性由线条、平涂形块、层叠逻辑和精细程度维持，不要求重复相同的云纹、珠环、角花或配色比例。

设计时先写一条可追溯的转译链：**文献／选定创作情境 → 场景或决定性瞬间 → 角色动作与环境关系 → 构图和纹样**。背景应让角色处于自己的世界，也可以承载正在发生的事件。形态证据和环境证据分开核实，具体图形转译属于原创设计。

- 优先选择能帮助辨识角色的环境线索或神话情境，凝练成主纹样及少量呼应；不把全部传说图标堆进一幅画。资料不足时说明创作依据，不编造古籍设定。
- 从完整画面安排曲直对比、运动方向、明暗大面、疏密和负形。背景可以疏静，也可以局部繁复；不要每幅都围绕主体做同样的旋涡和四角填充。
- 背景的微纹仍服从平面装饰语言，避免另起一种写实山水或三维场景风格。主体和背景有呼应，也有对比，不能互相伪装成器官。
- 连续制作时并置已有作品，检查主纹样、方向、明暗与留白、边缘形态是否过度相似。只换颜色或把云纹改称火纹，不算足够的变化；新意应来自与角色有关的构图决策。
- 简述本幅最值得看的设计，以及它与前作的联系与区别。不为求异硬塞无关元素，不为精美均匀加密纹样。共享局部笔法或小纹饰是允许的，避免的是整套背景方案机械复用。

例如，烛龙可把晦明语义转译为开阔暗明色域与横向层山；毕方可把章莪山的瑶碧、讹火语义转译为棱角岩片与稀疏火迹。两者是本次待验证方案，不是角色永久背景配方；证据见[角色档案](beasts.md)。

## 用决定性瞬间组织角色与环境

这是整体画风确认后的定制方法。角色特征回答“它是谁”，背景与场景回答“它此刻身处什么事件”；选择一个瞬间，将两方面联系起来。用户最新明确需要角色档案画，要求其他元素抽象化、符号化：场景提供姿态和语义，成图以完整角色为主，将地形、水势或事件痕迹凝练成少数平面装饰形块，不展开真实山水纵深。档案画仍可表现未完成的动作与张力，无须僵直摆正，也不添标签或信息栏。

环境符号应保留关系而非堆砌图标。例如烛龙的水面可缩为局部水纹带，但睁眼蛇首与闭眼人面倒影的位置、朝向和呼应仍需清楚。岩石可变为承托盘身的少数片面；远山、瀑布、花枝等若不能提供必要信息，就省略。此方法将故事浓缩进角色图版，不等于把环境完全删除。完整场景画仅在用户另行明确选择时采用。

- **先定时机。** 用一句话写明触发事件、当下动作和将发生的变化，选择蓄势、接触、转折或余波等最能表现角色的时刻。叙事场景通常表现同一瞬间，前因和后果通过可见线索暗示。若用户选择象征性并置，如烛龙中轴两侧的闭目夜色与开目白昼，则明确采用艺术性的时态并置，让视觉对应清楚，不把它误判为必须消除的时间矛盾。
- **动作与环境互相解释。** 从受力、重心、视线和接触点安排姿势，再设计环境此刻的状态。例如水势尚未回落、岩缝刚刚裂开、风向与羽片偏转相呼应；具体原因必须符合选定情节，不能随意赋予角色新能力。即使没有直接接触，环境也应说明角色为何在此作出这个动作。
- **让张力可见。** 未完成的动作、相反的运动方向、将闭合的间隙或即将接触的边缘都能形成悬念。用主曲线、遮挡和负形表达力量，张力可以安静，不必一律跳跃、咆哮或爆炸。
- **让环境属于这一瞬间。** 地形的可用空间、环境的变化与事件痕迹共同决定构图。自查：把背景换成另一只异兽的通用背景后，当前动作与故事是否还毫无损失？若是，角色与场景的联系可能仍弱。
- **先关系，后纹饰。** 缩略图上先读出动作、环境和视觉重心，再为水、岩、风等设计同一画法下的装饰形块与微纹。纹样强化运动和语义，避免装饰盖住动作、接触点与核心身份特征。
- **抓拍感保留在构图层。** 采用瞬间性的姿态和取景，继续用细线、平涂与叠层表现。无须引入摄影景深、运动模糊或三维打光。情节、抓拍时机和具体环境状态若为原创，应在档案中明确。

## 特别容易走偏的地方

- 写“壁画”后变成厚重石刻、粗线拓印：补充细线、轻盈曲线、平涂片块和原图参考。
- 写“精细”后变成全屏碎纹：指出需要留白的脸部、主躯干和背景区域。
- 新角色继承虎脸、爪、刺鬃、双翼：明确器官总数及本角色不采用的部位。
- 参考图局部裁切被新图沿用：当本次档案要求全身时，为喙尖、翼尖、尾尖、足爪预留清楚边距；输出后逐一检查。首轮毕方实测出现过上翼裁切，不能只凭主体已入画就判通过。
- 写“层次”后出现浮雕和立体打光：强调层次由边界与遮挡形成。
- 颜色相似但画法失配：先比较灰阶结构与线条，不能仅凭黛青朱砂判定同系列。
- 首轮背景同质化（用户实测反馈）：烛龙与毕方都沿用卷云、串珠弧线和四角框饰。下一版须改变有语义的背景主题及组织方式，同时检查是否保住共同画法；不能把原图背景当作必须复制的风格特征。
- 烛龙首轮结构（用户反馈）：蛇身混沌难辨、人头接蛇身突兀，观感诡异。本次先减少回绕与假身体环带，再统一头面与颈躯的尺度和连接；不靠增加装饰遮挡问题。
- 烛龙结构修订实测：早期编辑继承两个尾状尖端；08版虽可追踪头尾，用户仍认为丑，指出蛇形需要盘曲。15版已回到角色图版与抽象背景，但用户再次指出遮挡和盘绕不连续。因此形体美感与路径逻辑都要检查，完整保留旧曲线不是修图目标，装饰也不能替代连接修正。

除明确标为实测的项目外，以上是操作性风险说明，不把未看过的失败图说成实测证据。
