# 提示词模板

保留画风核心，填入角色特征和本次构图。不要同时粘贴多种相互冲突的角色档案。方括号是编写时的填项，提交生图前必须替换。

## 整体画风试稿

画风尚在确认时，先用这一简化模板。保留必要形态与完整的绘画质感，背景克制；不提前定制完整的神话场景、特定花框或配件。

```text
Use case: stylized-concept
输入图仅提供整体画风参考。画一幅[角色及必要核心形态]的代表性试稿，先让人判断是否延续同一种绘画语言。
继承参考图的[本次提炼的线条轻重、平面形块、叠层、细节尺度、色彩处理与整体气质]。
[简洁的主姿态和画幅]。细密纹饰服从身体走向，有明确的繁简和留白。保持完整装饰画的完成度，不降成草图。
背景采用不抢主体的安静底面与少量呼应形块，暂不安排完整叙事场景或具体边框。不要照搬参考角色的脸、肢体、姿态和整套背景。
本轮仅确认总体画法，不把偶然产生的发饰、局部花纹和环境当成永久设定。无文字、水印、三维光影或浮雕。
```

## 新角色结构稿／直接彩色稿

整体画风明确后，用以下模板展开角色与背景细节。

若采用故事瞬间，先填事件与角色—环境关系，再决定姿态和纹样。明确本次成图形式：当前角色图册以角色为视觉主体，环境抽象化、符号化；从故事提取动作和关系，不因此展开写实场景。仅在用户明确要完整场景画时描写其取景和纵深。静态展示可省略瞬间段，不把动态场面设为所有作品的要求。

```text
Use case: stylized-concept
用途：中国异兽图集的精细平面装饰插画。
输入图角色：[逐张列明：仅作系列画风参考，或本次编辑目标]。
创作一幅全新的[异兽名称]图。继承参考作品的线条质感、形块概括、细节层级和层叠逻辑。身体结构、姿态、背景主题、纹样、疏密与配色采用下面的新角色设计，不复制参考图的整套背景。

【形态与气质】
[文献明确的形态、器官数量与连接、可辨认的核心特征]。
[本次原创姿态、比例、情绪；把原创设计与原文事实分开记录]。
[若为复合形态，说明相邻部位的连续轮廓、比例、中轴和表面过渡，让它成为同一生物]。
保留核心身份，通过自然结构和有灵性的神态把奇异描述转译为可欣赏的形象。[本次气质]，不额外放大恐怖拼接感，也不统一变成幼态萌宠。

【决定性瞬间：叙事场景时填写】
[故事依据或明确标注的原创情境]。
画面凝固在[具体时刻]：角色正在[未完成或刚发生的动作]，环境此刻呈现[与事件有关的状态或反应]；以[可见线索]让人感到下一刻即将[变化]。
[重心、受力／接触点、视线、环境运动方向及其关系]。只表现这一瞬间，前因后果通过线索暗示。抓拍感来自姿态与构图，画法仍是精细平面装饰插画。

【构图】
[本次成图形式：角色档案画写清主体完整轮廓、主曲线、留白与环境符号；完整场景画才展开具体取景与景别。不要添加信息栏、标签或多视图。]
[由场景共同推导的画幅、主曲线、重心、主要负形、背景与主体关系]。
第一眼读出[动作与环境的主要关系，或静态图的整体形象]，第二眼认出[核心特征]，细看发现[纹样呼应]。关键部位清楚可读，不为展示所有表面强行改变取景。

【背景与本幅新意】
[文献或选定创作情境；说明具体图形是原创转译]。
[环境为什么在这个瞬间呈现这种状态，如何限制、推动或回应角色动作；静态场景写空间与气质关系]。
[主纹样的形状、方向和分组；它与主体的呼应及对比]。
[明暗大面、密集区、安静留白、边缘装饰或无框方案]。
[本幅最鲜明的视觉设计，以及与前作在哪些方面拉开区别]。
背景与主体使用同一种精细平面画法，支撑角色的独有世界。不要套用参考图的卷云、珠环、四角花饰组合；仅当本次设计明确需要时才用其中某种纹样。
[角色档案画中，将环境压缩为少量有意义的平涂片面和纹样，明确保留哪种动作、承托、接触或倒影关系；省去不必要的真实远景和摄影纵深。]

【画面语言】
壁画古意、剪纸般的形块关系、精细装饰插画的流动线条。将本角色身体概括成边界清晰的平面形块，形块内部平涂，靠遮挡、错位、穿插、嵌套和留白表现前后。
舒展主曲线统领画面；外轮廓、内部结构线、微纹有轻重层级。大轮廓、中层装饰形块、微小纹饰三级组织；纹样沿身体结构生长。脸部和核心识别部位保持清楚，以安静的大面衬托复杂区域。

【纹样与表面】
[针对该异兽的毛／羽／鳞等分组方案、密集区、安静区]。
轻微纸面或壁面质感，轮廓与纹饰清晰。

【本次输出阶段】
[黑白结构稿：仅中性黑白灰，少量可区分的灰阶平涂，无彩色和金色，包含完成的中层装饰；不是铅笔草稿。]
或
[彩色候选：列出主色、辅色、强调色及其部位，必要的文献颜色优先。]

【约束】
无文字、题签、标识、水印。避免写实肌肉、体积渐变、三维渲染、厚重投影、摄影光照、浮雕质感、统一粗黑线和卡通贴纸感。
避免均匀铺满碎纹；避免背景遮盖核心部位。不要复制参考角色的脸、肢体、姿态、翼形、虎纹或整套背景构图。[本角色的专门负面约束]。
```

## 在结构稿上上色

```text
Use case: precise-object-edit
第一张图是本次[异兽名称]黑白结构稿，是唯一编辑目标。第二张图是穷奇彩色风格参考，仅用于颜色的平面处理、细线和轻微纸壁质感。
只为第一张图上色，保留其画幅、所有外轮廓、姿态、器官数量和连接、主纹样边界、主要负形和背景构图。
具体配色：[色名及对应部位；遵守文献中有约束的颜色]。
单块平涂，色块通过色相或明度区别；细线采用[线色方案]。保留细密装饰、可读的脸与核心特征、疏密节奏。纸壁颗粒轻微。
背景配色：[服从本角色已设计的环境语义及明暗节奏，不自动套用穷奇底色]。
不要把穷奇的器官、虎纹、配色比例、云纹、边框或构图带进来。不要重画脸和身体，不添加或删去器官，不用光照渐变塑造体积，不添加文字。
```
