# 异兽装饰壁画

把同一套绘画语言迁移到不同异兽，交付可回溯的提示词、图像和待验收记录。当前风格基准是用户认可的穷奇稿；新试稿不自动取得基准地位。

图册的重要目标是把文字中显得诡异的异兽转译为可接受、值得欣赏的形象。保留核心辨识特征，通过自洽的形体、自然连接、清楚轮廓和有灵性的神态消化陌生感；不把不同器官机械拼接，也不把所有角色统一改成幼态萌宠。具体美感仍由用户判断。

## 先整体画风，后细节定制

按用户最新要求，把两层决策分开：

1. **整体画风确认。** 从已认可参考图提炼线条、平面化程度、形块层叠、装饰繁简、色彩处理与整体气质；用代表性试稿让用户判断总体观感。角色只保留必要的身份特征，背景保持服务画风判断的简洁程度，不同时推进具体山形、火迹、边框或纹样故事。此时反馈聚焦“是不是想要的画法与气质”，不让局部修改掩盖风格问题。
2. **按角色与场景定制。** 用户认可整体画风后，分别梳理角色特征与故事环境，再以两者的关系组织动作、背景和构图。可以选择故事中的决定性瞬间，让动作张力与环境独特性同时成立，再细化身体纹样、边缘装饰及配色。故事是动作与纹样的来源，不自动规定成图为完整场景画；当前图册需要角色档案画的主体感，环境应抽象为有角色语义的形块和符号。此前提出的背景差异化要求在这一阶段落实，系列变化不能改变已确认的核心画法。

已经明确认可并要求沿用的画风直接复用，不重复要求确认。用户明确要求开始某个角色的定制时，按该范围继续，不再设置额外的画风确认门槛；这不等于旧试稿的形态和背景均已认可。当前穷奇是已认可的单幅视觉参考，跨角色试稿仍待人工确认；背景修订图仅为探索，不反向定义整体画风。若用户明确要求跨阶段测试，可生成预览，但不得把后阶段探索当成已经确认的设计。

## 先读什么

- 开始系列设计或生图：读 [风格规范](references/style.md)，用图像查看工具实际查看 `assets/qiongqi-approved-gray.png` 与 `assets/qiongqi-approved-color.png`。文字不能替代看图。
- 编写或调用生图提示词：读 [提示词模板](references/prompts.md)。生成前填入本次角色的具体设计，删除不适用的段落。
- 设计烛龙或毕方：按需读 [已核实形态档案](references/beasts.md)；其他异兽查相应原文，不类推其身体结构。
- 需要追溯认可过程或素材来源：读 [来源与状态](references/provenance.md)。

所有资源路径相对于本 Skill 文件夹解析。将实际采用的本地图片作为生图工具输入；仅在提示词里写文件名不会传入图像。调用当前环境可用的 `image_gen`，并遵循 `imagegen` Skill 的工具使用方式。无法调用时如实记录未运行，不把提示词交付冒充生图测试。

## 确定本次范围

从用户要求选择阶段，已有的信息直接沿用：

| 请求 | 执行范围 |
| --- | --- |
| 先确定画风、画风还不对 | 回到整体画风提炼与试稿比较，暂存具体细节建议，先不继续定制背景和纹样 |
| 只写提示词、制定方案 | 交付角色档案和完整提示词，不擅自生成图片 |
| 新画一只异兽，未指定阶段 | 先交一张黑白结构稿供选择，再按反馈上色 |
| 上色、改颜色 | 用用户指定或认可的稿件作为编辑目标，保留其结构 |
| 直接要彩色稿 | 直接生成彩色候选，不额外设置黑白审批步骤 |
| 测试此 Skill、验证迁移 | 可连续生成结构稿与彩色试稿，先自查显著结构错误；所有输出标为待人工验证 |
| 修改已有图 | 定位指定版本，只改变用户点名的问题 |

画风迁移测试可选两个与基准体型不同的角色，如长躯体与鸟类，先比较共同画法；进入细节阶段后才展开各自的环境方案。已有测试范围或预算时服从用户范围。小样本只验证流程和明显偏差，不声称已证明稳定性。

## 角色档案与构图决策

以下用于细节定制阶段。画风探索时只核实必要的核心形态，其他设计点暂存，不提前变成固定要求。

区分内部角色档案与成图形式。当前用户要求角色档案画的主体感：完整形象与主曲线占主要视觉重量，岩、水、风等环境凝练为平面形块和象征纹样，保留动作及故事的关键关系，不铺开写实山水空间。档案画不等于信息卡、僵直正面或添文字标签；姿态仍可有张力。只有用户另行明确选择完整场景画时，才展开近中远景与环境取景。

1. 写明采用的文献、篇章、原文链接和关键短引；区分正文、注释、异说及原创演绎。存在冲突时选定一种形态并说明。不要为了丰富而叠加互不相容的版本。
2. 提取最有辨识力的核心特征，尤其核对头、足、翼、尾的数量及连接关系。直接描绘复合形态时，协调相邻部位的尺度、轴线、轮廓和表面过渡，先解决形体关系再增加纹饰。用户明确采用象征性改编时，如实体蛇首与倒影人面，按其表达关系设计并注明原创演绎，不强行改回实体器官拼接。不能靠发丝、云气或首饰掩住接合问题，也不擅自把核心特征全部换成身上的图标。
3. 把文献的颜色要求列为角色约束，再选择具体矿物色和比例。未规定颜色的部分可设计。不得把穷奇的黛青、朱砂比例当作全系列配方。
4. 分别确定角色特征与故事环境。采用叙事场景时，按[风格规范](references/style.md)选择一个决定性瞬间：角色正在做什么、环境此刻如何变化、下一刻将发生什么。区分原典情节与原创演绎，不把新编情节说成古籍事实；静态展示也可保留，不强迫每幅成为动作场面。
5. 从这个瞬间共同推导主曲线、姿态、重心、视线、接触关系和环境反应，再选画幅、负形及观看方向。背景可由地形、水势、风向、事件痕迹等形成独特性；具体纹样随后依附这些结构，不先画完固定姿态再拼装通用景片。“抓拍”指瞬间选择与构图，沿用平面装饰画法。
6. 写出观看顺序：先见整体动势，再认核心特征，最后发现主体与环境的纹饰呼应。背景具有叙事作用，同时让关键足、头和连接点清晰。与已有系列图并置，说明本幅最鲜明的新意；主题、构图和节奏都相近时，先改方案，不靠换色或添碎纹解决。

档案至少包含：名称／采用版本与证据／核心特征／原创演绎／场景与环境／姿态与构图／身体纹样／背景语义与纹样转译／配色／与已有作品的差异／避免混入的其他角色特征。采用叙事瞬间时，另写清事件触发、当下动作、环境反应与下一刻的悬念。

## 生成与修订

### 黑白结构稿

用认可的灰阶图作为画风参考，要求完成中层装饰与微纹组织，不能只交线稿或剪影。以少量可区分的平涂灰阶表达遮挡、穿插、嵌套和负形；没有体积光影。记录实际提交的完整提示词及参考图顺序。

生成后实际看图，先排查显著的形态硬错误，再看缩略图的总体画法、主轮廓与大中小尺度。细节定制阶段的背景也在结构稿中设计完成，并与前作比较；不能等到上色时才靠色相变化制造区别。画风确认阶段采用简化环境，避免以背景故事和复杂配件干扰判断。

### 保形上色

把本次结构稿作为第一张输入并明确标为“编辑目标”；把认可彩色穷奇稿作为第二张输入并标为“仅参考绘画语言”。要求保留外轮廓、姿态、头足翼尾数量、连接、主要纹样边界、画幅和留白，只改平涂色与线色。

检查相邻色块的区分、角色文献颜色、细线是否依然清楚，以及上色是否偷偷增加器官或改动纹饰。材质是轻微的纸壁颗粒，不能变成石雕、金属浮雕或厚涂。

### 定点修图

用“部位＋观察到的问题＋具体改变＋需保留内容”描述。例如：只让毕方的一条腿从腹部到脚爪连续可见，清掉腿前遮挡云纹，保留头、双翼、主体位置、线条密度和其他图案。

用户仅要求背景修改时，按角色语义重设计背景及必要的边缘装饰，明确主体哪些部分保持。若要求以故事瞬间重构全图，则联动设计动作与环境，保留核心身份特征，不误锁旧姿态。新创作从主体与背景的整体构图开始；局部换背景仅用于明确要求的局部编辑。

每轮只针对最影响识别或画风的一项问题。常规测试每个角色初稿、上色各一张，最多一次有明确理由的修正；仍不满意时保留版本与问题交人工决定，避免无限抽图。用户要求更多变体时按其范围执行。

## 验证与交付

先确认整体画风是否成立，再讨论定制细节。画风探索阶段以画风和总体偏好为主要验收项，尚未设计的背景细节记为“未进入本阶段”。

将这五项分别写成“通过／需修改／待人工判断”，附实际观察，不合成虚假的精确总分：

- **形态**：核心特征、数量、连接及角色气质是否成立；能否追踪完整身体，复合部位是否自然，是否出现令用户不适的拼接感；无法看清算不确定。
- **画风**：细线轻重、平面形块、舒展主曲线、三级密度与负形是否接近基准。
- **场景与系列变化**：背景是否与角色有关，叙事场景的动作和环境反应是否属于同一瞬间；用户指定象征性并置时，角色状态与两侧环境的对应是否清楚。张力、独有的方向与疏密能否从画面读出，并置时是否保持共同画法。
- **保形**：上色或局部修改后，有没有改变应锁定的构图和部位。
- **人工偏好**：精美程度、古意、神秘感、是否像同一系列，由用户确认。

每次输出保存到工作区独立目录，例如 `output/mythic-beast-mural/<日期>-<任务>/`。保留角色档案、逐次完整 prompt、输入图路径与角色、输出图路径、工具、时间、版本关系和检查记录。若工具不暴露模型、seed 或尺寸设置，记为未提供，不编造。

向用户直接展示图片，链接完整提示词和验收记录。清楚区分“工具已生成”“agent 已检查”“用户已认可”；只有用户明确认可的版本才能成为后续基准。收集反馈时优先问：哪张更对味、哪个部位需改、背景是否贴合角色且有新意、是否可以锁定结构或颜色。
